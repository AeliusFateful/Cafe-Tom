# Кафе «Томь»: сайт

Статичный сайт без сборки: открывается двойным щелчком по `index.html` или любым веб-сервером.

## Как поменять меню и цены

Все блюда лежат в `src/menu.json`: название, цена, вес, описание и картинка (имя файла из `img/` без `.jpg`).
После правки запустите из корня проекта:

```
node src/build.mjs
```

Скрипт пересоберёт `index.html` (нужен Node 18+). Описания длиннее двух строк раскрываются кнопкой «Подробнее» автоматически.

## Что где

- `src/template.html` — разметка страницы, `src/menu.json` — меню, `src/build.mjs` — сборка.
- `css/styles.css`, `js/main.js` — стили и скрипты (меню, «стол» для заказа навынос, бронь через WhatsApp).
- `img/` — фотографии (блюда, зал, фасад, эмблема), `fonts/` — Jost и Onest (кириллица, хранятся локально).
